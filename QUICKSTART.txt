========================================================================
  DRIVERCHECK - GPU & SYSTEM CRASH DIAGNOSTIC SUITE
========================================================================

QUICK START GUIDE:
1. Extract all contents of this ZIP file to a folder.
2. Double-click "Run-Diagnostics.bat"
3. Select Option [1] "Full Crash Diagnostics + Open HTML Report".
4. An interactive dark-mode HTML report (CrashReport_<timestamp>.html)
   will automatically generate and open in your default browser.

------------------------------------------------------------------------
WHAT THIS TOOL DIAGNOSES:
------------------------------------------------------------------------
1. GPU Driver Timeouts (TDR / Event 4101 / 0x141)
   - Checks if the display driver hung or stopped responding.
   - Diagnoses TdrDelay, TdrLevel, and Hardware Accelerated Scheduling.

2. Shader Compilation Crashes & Shader Timeouts
   - Identifies crashes in shader compiler DLLs (amdxc64.dll, amdxx64.dll,
     nvwgf2umx.dll, oo2core_*.dll).
   - Distinguishes between corrupt shader caches and CPU/RAM instability
     during heavy AVX2/AVX-512 shader compilation.

3. Black Screens & Instant Reboots
   - Correlates Kernel-Power Event 41 (BugcheckCode 0), unexpected shutdowns
     (Event 6008), and PSU transient spike power trips.

4. PCIe Bus & Riser Cable Errors (WHEA Event 17)
   - Scans WHEA-Logger for PCIe root port link communication errors caused
     by PCIe 4.0/5.0 riser cables or loose GPU slot seating.

5. Out-of-Memory / Pagefile Exhaustion (Event 2004)
   - Flags when games crash due to Windows running out of commit limit or
     disabled/insufficient Windows Paging File.

6. Dual-GPU Driver Desync & Downgrade Prevention
   - Detects driver version conflicts between AMD discrete Radeon GPUs and
     integrated CPU graphics.
   - Provides 1-click protection against Windows Update silently replacing
     official graphics drivers with older OEM drivers.

7. Game Engine Logs & Minidumps
   - Inspects Unreal Engine (D3D device lost), Unity, idTech, Godot, and
     binary crash minidumps (0xC0000005, 0x887A0006 DXGI device lost).

8. DisplayPort 1.2a Scaler Saturation & EDID Factory Overclocks
   - Detects monitors with aggressive factory overclocks (e.g., 1440p 165Hz
     with bloated vertical blanking >1500 lines, pixel clock >585 MHz)
     saturating budget monitor scalers and causing periodic 2-3s blackouts
     (HPD renegotiations) with NO Windows TDRs or crash dumps.

9. PCIe Link State Power Management (ASPM) Timeouts
   - Detects when aggressive PCIe ASPM power saving states (Moderate/Maximum)
     cause high bus resumption latencies on PCIe 4.0/5.0 motherboards,
     triggering GPU display driver timeouts (TDR 4101 / 0x141) during low-load
     scenarios (web browsing, YouTube, Discord).
   - Provides 1-click remediation via "Run-Diagnostics.bat" -> Maintenance [6].

10. Rogue Kernel Port I/O Drivers & INVALID_KERNEL_HANDLE (0x93)
   - Audits legacy/rogue direct hardware port I/O drivers (inpoutx64.sys,
     WinRing0, ene.sys, AsrOmgDrv.sys, gdrv.sys) left behind by RGB/fan tools.
   - Diagnoses anti-cheat collisions (Easy Anti-Cheat, BattlEye, Vanguard)
     that cause full-system game freezes (where audio keeps playing) or
     instant BugCheck 0x93 BSODs.
   - Provides 1-click disabling via "Run-Diagnostics.bat" -> Maintenance [7].

11. Motherboard, BIOS & Platform Chipset Driver Health
   - Audits motherboard model and BIOS release version/date to identify
     outdated firmware (>3 years) lacking PCIe 4.0/5.0 AGESA stability fixes.
   - Audits official AMD Chipset Software / Intel Chipset Device Software
     installations and verifies core platform controllers (AMD GPIO, I2C,
     PCI Device Driver, PSP, and 3D V-Cache Optimizer).

12. Steam Watchdog IPC Hangs & Network Link Drops
   - Diagnoses Steam engine stalls and cross-thread pipe watchdog terminations
     (Assert( Stalled cross-thread pipe )) which abruptly terminate games.
   - Correlates socket hangs with network ARP probe failures (NCSI Event 4042)
     and wireless failovers on Intel 2.5GbE adapters (I225-V / I226-V).
   - Provides safe 1-click remediation via "Run-Diagnostics.bat" -> Maintenance [5]
     to disable Packet Priority & VLAN while preserving active negotiated link speed.
