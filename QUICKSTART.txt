========================================================================
  DriverCheck - Game & PC Crash Troubleshooter
========================================================================

QUICK START:
1. Extract all contents of this ZIP file to a folder.
2. Double-click "Run-Diagnostics.bat"
3. Select Option [1] "Crash check and Report".
   (Or select Option [2] "Check full crash history" to scan all recent incidents).
4. An HTML report (CrashReport_<timestamp>.html) will open in your browser,
   and the terminal will show a numbered menu of any recommended fixes you
   can apply right away.

------------------------------------------------------------------------
WHAT THIS TOOL CHECKS:
------------------------------------------------------------------------
1. GPU Driver Timeouts (TDR / Event 4101 / 0x141 / 0x193)
   - Checks if the display driver stopped responding or hit a watchdog timeout.
   - Checks TdrDelay, TdrLevel, and Hardware-Accelerated GPU Scheduling.

2. Shader Compilation Crashes & Corrupted Shader Caches
   - Identifies crashes in shader compiler DLLs (amdxc64.dll, amdxx64.dll,
     nvwgf2umx.dll, oo2core_*.dll).
   - Provides one-step shader cache cleanup (DirectX D3DSCache, AMD DxCache,
     DxcCache, VkCache, and NVIDIA DXCache).

3. Black Screens & Unexpected Reboots
   - Checks Kernel-Power Event 41 (BugcheckCode 0) and unexpected shutdowns
     (Event 6008).

4. PCIe Bus & Riser Cable Errors (WHEA Event 17)
   - Scans WHEA-Logger for PCIe link communication errors caused by riser
     cables or slot seating issues.

5. Out-of-Memory / Pagefile Exhaustion (Event 2004)
   - Flags when games crash because Windows ran out of virtual memory commit
     space or has a disabled/undersized pagefile.

6. GPU Driver Status & Windows Update Overwrite Protection
   - Detects driver version mismatches between discrete GPUs and integrated
     CPU graphics.
   - Can lock Windows Update from silently overwriting your GPU driver with
     an older version.

7. Game Engine Logs & Crash Dumps
   - Inspects Unreal Engine, Unity, idTech, Godot, Steam, Windows WER, and
     kernel watchdog crash dumps (0xC0000005, 0x887A0006, 0x141, 0x193).

8. Monitor Refresh Rate & DisplayPort Bandwidth Limits
   - Checks monitor EDID timings for high pixel clocks or vertical blanking
     that can cause brief 2-3s black screens on DisplayPort 1.2a monitors.

9. PCIe Slot Power Saving (ASPM) Timeouts
   - Checks if PCIe Link State Power Management is enabled and causing GPU
     driver timeouts when waking the PCIe link.

10. Conflicting RGB / Hardware Monitor Kernel Drivers (0x93)
   - Checks for legacy direct port I/O drivers (inpoutx64.sys, WinRing0,
     ene.sys, AsrOmgDrv.sys, gdrv.sys) that conflict with game anti-cheat.

11. Motherboard, BIOS & Chipset Drivers
   - Checks motherboard model, BIOS date, AMD/Intel chipset driver versions,
     and Device Manager error codes (Code 28 / Code 43).

12. Network Connection Drops & UDP Port Exhaustion
   - Checks for PCI network controller resets (Event 1), Ethernet link drops
     (Event 4042), Steam watchdog pipe stalls, and UDP port exhaustion
     (Event 4266).
